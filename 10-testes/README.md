# Testes de Software

## Por que este tópico é importante?

Testes permitem evoluir o sistema com confiança. Um bom conjunto de testes protege regras importantes e detecta regressões sem depender apenas de validação manual.

## O que estudar

- [ ] testes unitários
- [ ] testes de integração
- [ ] testes end-to-end
- [ ] test doubles
- [ ] mocks, stubs e fakes
- [ ] testes de contrato
- [ ] pirâmide de testes
- [ ] testabilidade
- [ ] fixtures
- [ ] testes de regressão

## Materiais de estudo

- Livro: Growing Object-Oriented Software, Guided by Tests — Freeman e Pryce
- Livro: xUnit Test Patterns — Gerard Meszaros

## Exercícios práticos

- [ ] Definir quais testes seriam necessários para uma regra de cálculo financeiro.
- [ ] Criar uma estratégia de testes para uma API com banco e serviço externo.
