# 05 — Testes de Software

## Objetivo
Criar uma rede de segurança antes das grandes refatorações do projeto.

## Conteúdo
- unitários, integração e E2E;
- pirâmide de testes como heurística;
- doubles: mock, stub e fake;
- determinismo e isolamento;
- testes de regras versus detalhes de implementação;
- contratos e regressão.

## Evolução do e-commerce
Adicionar testes para catálogo, pedido, estoque e persistência antes de mudar a arquitetura.
