# 07 — Design de Software

## Objetivo
Melhorar decisões locais de código sem transformar princípios em dogmas.

## Conteúdo
SOLID, KISS, YAGNI, DRY, composição, interfaces, abstrações, dependency inversion, coesão e acoplamento.

## Evolução
Revisar o código do e-commerce e aplicar somente mudanças justificadas por legibilidade, testabilidade ou desacoplamento.
