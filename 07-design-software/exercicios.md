# Exercícios — Design

Analise o projeto e encontre:
- um ponto com responsabilidade excessiva;
- uma duplicação relevante;
- uma dependência difícil de testar;
- uma abstração que existe sem necessidade.

Faça mudanças pequenas. Para cada uma, escreva: problema observado, princípio relacionado, alteração feita e trade-off.
