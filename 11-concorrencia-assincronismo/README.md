# Concorrência e Processamento Assíncrono

## Por que este tópico é importante?

Sistemas backend frequentemente processam múltiplas operações ao mesmo tempo. Entender concorrência ajuda a evitar race conditions, duplicidades e inconsistências.

- [ ] backpressure

- Livro: Designing Data-Intensive Applications — Martin Kleppmann

## Exercícios práticos

- [ ] Projetar um processamento de jobs com múltiplos workers sem processar o mesmo trabalho duas vezes.
- [ ] Descrever como impedir duplo pagamento causado por requisições concorrentes.
