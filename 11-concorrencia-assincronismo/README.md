# 11 — Concorrência e Assincronismo

## Objetivo
Entender operações simultâneas e diferenciar concorrência, paralelismo e trabalho assíncrono.

## Problema do projeto
Existe uma unidade em estoque e duas compras chegam quase ao mesmo tempo.

## Conteúdo
race conditions, critical sections, locking otimista/pessimista, atomic operations, concorrência, paralelismo, async I/O e workers em nível introdutório.
