# Arquitetura de Software

## Por que este tópico é importante?

Arquitetura organiza responsabilidades e dependências. Isso torna sistemas maiores mais fáceis de testar, manter e evoluir sem espalhar mudanças por toda a aplicação.

## O que estudar

- [ ] separação de responsabilidades
- [ ] coesão e acoplamento
- [ ] arquitetura em camadas
- [ ] modularização
- [ ] dependency inversion
- [ ] Clean Architecture
- [ ] arquitetura hexagonal
- [ ] monólito modular
- [ ] trade-offs arquiteturais

## Materiais de estudo

- The Twelve-Factor App: https://12factor.net/pt_br/
- AWS Well-Architected Framework: https://docs.aws.amazon.com/pt_br/wellarchitected/latest/framework/welcome.html
- Livro: Clean Architecture — Robert C. Martin

## Exercícios práticos

- [ ] Desenhar a arquitetura de uma API simples e justificar cada camada.
- [ ] Comparar uma arquitetura em camadas com um monólito modular.
