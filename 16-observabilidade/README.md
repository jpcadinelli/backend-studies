# Observabilidade

## Por que este tópico é importante?

Em produção, não basta saber que algo falhou. Observabilidade permite investigar comportamento interno usando logs, métricas e traces.

## O que estudar

- [ ] logs estruturados
- [ ] métricas
- [ ] tracing distribuído
- [ ] correlation IDs
- [ ] health checks
- [ ] SLI, SLO e SLA
- [ ] alertas
- [ ] OpenTelemetry
- [ ] dashboards
- [ ] diagnóstico de incidentes

## Materiais de estudo

- OpenTelemetry Documentation: https://opentelemetry.io/docs/
- OpenTelemetry Concepts: https://opentelemetry.io/docs/concepts/

## Exercícios práticos

- [ ] Definir logs e métricas necessários para diagnosticar uma API lenta.
- [ ] Desenhar um trace atravessando API, banco, fila e serviço externo.
