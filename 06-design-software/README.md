# Princípios de Design de Software

## Por que este tópico é importante?

Princípios de design ajudam a reduzir complexidade e tornar mudanças mais seguras. O objetivo não é aplicar padrões mecanicamente, mas reconhecer quando uma abstração realmente ajuda.

## O que estudar

- [ ] SOLID
- [ ] KISS
- [ ] DRY
- [ ] YAGNI
- [ ] composição
- [ ] interfaces
- [ ] abstrações
- [ ] dependency injection
- [ ] design patterns
- [ ] refatoração

## Materiais de estudo

- Livro: Refactoring — Martin Fowler
- Livro: A Philosophy of Software Design — John Ousterhout
- Livro: Design Patterns — Gamma, Helm, Johnson e Vlissides

## Exercícios práticos

- [ ] Identificar uma classe ou módulo com muitas responsabilidades e propor uma refatoração.
- [ ] Revisar uma abstração e avaliar se ela resolve um problema real ou apenas aumenta complexidade.

Considere o tópico bem compreendido quando você conseguir explicar os conceitos principais com suas próprias palavras, identificar quando aplicá-los e discutir pelo menos um trade-off ou problema real relacionado ao assunto.
