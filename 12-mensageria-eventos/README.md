# Mensageria e Arquitetura Orientada a Eventos

## Por que este tópico é importante?

Mensageria permite desacoplar componentes e processar operações de forma assíncrona. É essencial entender também entrega, confirmação, retry e falhas.

- [ ] retry

- [ ] ordering
- [ ] delivery guarantees
- [ ] event-driven architecture
