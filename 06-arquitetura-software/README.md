# 06 — Arquitetura de Software

## Objetivo
Aprender a organizar um sistema que cresceu, usando os problemas reais do e-commerce existente.

## Conteúdo
- separação de responsabilidades;
- coesão e acoplamento;
- camadas e limites;
- dependências;
- arquitetura hexagonal/ports and adapters;
- Clean Architecture como conjunto de ideias, não como estrutura obrigatória;
- monólito modular.

## Evolução do projeto
Refatorar sem mudar comportamento. A suíte do módulo 05 deve comprovar isso.
