# 08 — Domain-Driven Design

## Objetivo
Modelar regras de negócio explicitamente agora que o projeto possui domínio suficiente.

## Conteúdo
- domínio e subdomínio;
- linguagem ubíqua;
- entidade e value object;
- aggregate e aggregate root;
- repository;
- domain service;
- bounded context;
- invariantes.

## Evolução
Revisar `Product`, `Customer`, `Order`, `OrderItem`, `Inventory` e `Payment` e decidir onde as regras realmente pertencem.
