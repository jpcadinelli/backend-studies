# Exercícios — Fundamentos da Web e HTTP

Este módulo não exige código.

## Revisão

Responda com suas próprias palavras:

1. Qual é a diferença entre cliente e servidor?
2. O que o DNS resolve antes de uma comunicação com um domínio?
3. Qual é a diferença entre HTTP e HTTPS?
4. O que diferencia uma request de uma response?
5. Para que servem métodos como GET, POST, PUT/PATCH e DELETE?
6. O que as famílias 2xx, 4xx e 5xx representam?
7. Para que servem headers HTTP? Cite dois exemplos de informação que podem transportar.
8. O que significa dizer que HTTP é stateless?
9. Qual é o papel de cookies em aplicações web?
10. Descreva, em ordem aproximada, o que acontece entre digitar uma URL e receber uma página/resposta do servidor.

## Observação opcional

Abra o DevTools do navegador, acesse um site e identifique na aba de rede:

- URL;
- método;
- status code;
- request headers;
- response headers;
- tempo da requisição.

Não altere nem programe nada. O objetivo é apenas reconhecer no mundo real os conceitos estudados.
