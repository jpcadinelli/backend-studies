# Materiais — Fundamentos da Web e HTTP

## Leitura principal

- [MDN — Overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview) — introdução clara ao modelo cliente-servidor, mensagens e fluxo HTTP.
- [MDN — HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP) — referência para métodos, headers, status, cookies e cache.

## Especificação

- [RFC 9110 — HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110) — fonte normativa. Não precisa ser lida inteira no primeiro contato; use para consultar conceitos e semântica.
- [MDN — HTTP resources and specifications](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Resources_and_specifications) — mapa das principais RFCs atuais.

## Livro opcional

- **Computer Networking: A Top-Down Approach**, James Kurose e Keith Ross — útil para aprofundar DNS, TCP, HTTP e a pilha de rede sem transformar este roadmap em um curso completo de redes.

## Como consumir

1. Comece pelo overview da MDN.
2. Use DevTools enquanto lê para relacionar teoria com tráfego real.
3. Consulte a RFC apenas nos pontos que quiser validar com mais precisão.
