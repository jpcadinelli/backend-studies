# 20 — System Design

## Objetivo
Consolidar o roadmap projetando a evolução do e-commerce para diferentes escalas e requisitos.

## Conteúdo
requirements, estimativas, bottlenecks, availability, consistency, partitioning, caching, queues, storage, failure modes e trade-offs.

## Resultado final
Produzir arquitetura do e-commerce justificando decisões e distinguindo o que é necessário agora do que só seria necessário em escala maior.
