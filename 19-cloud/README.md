# 19 — Cloud

## Objetivo
Entender os serviços básicos necessários para executar o sistema fora do ambiente local sem transformar o módulo em certificação de um provedor.

## Conteúdo
compute, networking, load balancer, managed database, object storage, secrets, autoscaling, regions/zones, custos e responsabilidade compartilhada.

## Evolução
Fazer deploy do e-commerce usando um provedor como implementação de referência e documentar as escolhas.
