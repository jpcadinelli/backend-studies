# 14 — Sistemas Distribuídos

## Objetivo
Entender problemas que surgem quando banco, API, cache e broker podem falhar independentemente.

## Conteúdo
partial failure, timeout, retry/backoff, idempotência, consistência eventual, CAP com cuidado, circuit breaker, transactional outbox e saga em nível adequado.

## Evolução
Tornar processamento de pedido/evento resistente a duplicações e falhas parciais.
